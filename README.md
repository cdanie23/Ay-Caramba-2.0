# Ay-Caramba-2.0
## How to run the project
### 1) Unzip and import Ay-Caramba-2.0 into your favorite Java IDE
### 2) Run the Server/src/main.java
### 3) Run the Client/src/main.java 
### 4) Enter the branch name you wish to send data from in the console
### 5) Client will handle the rest and terminate.
